# Screenshots

[English](README.md) | [Русский](README.ru.md)

Fresh frames of the current build (dev, perf HUD visible in race shots). Desktop screens are 1600 px wide; `thumbs/` keeps the 640 px versions the README tables use — each thumb links to the full-size file.

Desktop:

- `home.png` / `home-dark.png` — landing, light and dark theme
- `tracks.png` — track list from the API (three tracks, weather)
- `garage.png` — garage, 5 GLB bodies
- `login.png` — auth
- `profile.png` — profile: aggregate stats, per-track bests, achievements
- `leaderboard.png` — per-track leaderboard
- `race-1.png` — Coastal Oval, chase camera: HUD, minimap, perf HUD
- `race-2.png` — Night City
- `race-3-camera-bumper.png` / `race-3-camera-tv.png` — Storm Eight, bumper and TV cameras
- `finish.png` — SEGA-style finish moment

`mobile/` — phone layouts: `home-mobile.png`, `tracks-mobile.png`, `garage-mobile.png`, `leaderboard-mobile.png`, `profile-mobile.png`.

Videos: source `.mov` and the ≤10 MB README clips (`.mp4`) live in `docs/video/` and are gitignored; the READMEs embed them as github.com/user-attachments links. Recording & update flow: [docs/development.md](../development.md#gameplay-media).
