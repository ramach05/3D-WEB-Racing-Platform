# Скриншоты

[🇬🇧 English](README.md) | 🇷🇺 **Русский**

Свежие кадры текущей сборки (dev, в кадрах заезда виден perf-HUD). Десктопные экраны — 1600 px в ширину; в `thumbs/` лежат версии 640 px для таблиц README, каждая превьюшка ссылается на полноразмерный файл.

Десктоп:

- `home.png` / `home-dark.png` — лендинг, светлая и темная темы
- `tracks.png` — список трасс из API (три трассы, погода)
- `garage.png` — гараж, 5 GLB-кузовов
- `login.png` — аутентификация
- `profile.png` — профиль: сводная статистика, рекорды по трассам, достижения
- `leaderboard.png` — лидерборд по трассе
- `race-1.png` — Coastal Oval, chase-камера: HUD, миникарта, perf-HUD
- `race-2.png` — Night City
- `race-3-camera-bumper.png` / `race-3-camera-tv.png` — Storm Eight, bumper- и TV-камеры
- `finish.png` — SEGA-момент финиша

`mobile/` — мобильные экраны: `home-mobile.png`, `tracks-mobile.png`, `garage-mobile.png`, `leaderboard-mobile.png`, `profile-mobile.png`.

Видео: исходные `.mov` и ролики для README (`.mp4` ≤10 МБ) лежат в `docs/video/` и не попадают в git; в README они встроены ссылками github.com/user-attachments. Запись и обновление: [docs/development.ru.md](../development.ru.md#медиа-запись-и-обновление).
